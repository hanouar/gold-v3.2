   ideally 2012-present. The public H4 file used for testing is a stand-in.

     python validate_data.py --xauusd data/your.csv [--data-tz Europe/Athens] [--ts-convention open]

3) Run the leak test on YOUR file:
     python tests/test_no_leak.py --xauusd data/your.csv [same data args]

     python walk_forward_multitask.py --xauusd data/your.csv --holdout-start 2023-01-01
5) Any new feature, data source or model must beat core3 AND the current model on the
   development period, and must not degrade the holdout.
